# Plantillas controladas · GC-00/003/03

Por control de configuración, las plantillas binarias no se incluyen en el repositorio.

Instalación:

```
pnpm templates:changes:install -- --annex-iii "<Anexo III.docx>" --annex-iv "<Anexo IV.docx>" --annex-v "<Anexo V.docx>"
```

El instalador valida los SHA-256 auditados antes de copiar los archivos a este directorio.
